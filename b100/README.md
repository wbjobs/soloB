# FPGA 固件管理器 (批量升级 + A/B 双备份)

基于 Electron + React 的 FPGA 固件管理桌面应用，通过 WebUSB 协议实现 FPGA 设备的固件管理功能。

## ✨ 核心特性

### 🚀 批量升级功能 (新!)
- **最多支持10个设备** - 同时连接和管理最多10台 FPGA 设备
- **并行升级** - 所有设备同时进行固件升级，大幅提升效率
- **实时吞吐量** - 显示每个设备的传输速度 (KB/s)
- **进度跟踪** - 每个设备独立显示升级进度百分比
- **故障隔离** - 单个设备升级失败不会影响其他设备
- **独立控制** - 支持单设备取消、重置、刷新操作
- **批量统计** - 实时显示成功/失败/升级中/等待数量和成功率

### 🔒 A/B 双备份防砖机制
- **双分区设计**: FPGA 侧保留两个独立的固件分区 (A/B)
- **安全升级**: 固件始终写入非活动分区，验证成功后才切换启动分区
- **断电保护**: 升级过程中任何时候断电都不会变砖，系统将从原分区启动
- **一键回滚**: 快速回滚到上一个稳定版本

### 其他功能
1. **WebUSB 设备连接** - 自动识别 VID/PID 为 `0x0403/0x6014` 的 FPGA 设备
2. **固件信息读取** - 读取当前固件版本号和 CRC 校验值
3. **分块传输** - 将固件文件按 **1024字节** 分块发送到 Bootloader
4. **完整性验证** - 写入完成后验证固件完整性
5. **升级日志** - 所有升级操作记录到本地 IndexedDB

## 技术栈

## 🔧 通信协议

### USB 命令定义

| 命令 | 值 | 说明 |
|------|-----|------|
| `GET_VERSION` | `0x01` | 获取固件版本 |
| `GET_CRC` | `0x02` | 获取 CRC 校验值 |
| `UPLOAD_START` | `0x03` | 开始上传 |
| `UPLOAD_CHUNK` | `0x04` | 上传数据块 |
| `UPLOAD_END` | `0x05` | 结束上传 |
| `VERIFY` | `0x06` | 验证固件 |
| `SWITCH_PARTITION` | `0x07` | 切换启动分区 |
| `GET_PARTITION_INFO` | `0x0C` | 获取分区信息 |
| `SET_ACTIVE_PARTITION` | `0x0D` | 设置激活分区 |
| `GET_ACTIVE_PARTITION` | `0x0E` | 获取当前激活分区 |
| `ERASE_PARTITION` | `0x0F` | 擦除分区 |
| `MARK_PARTITION_VALID` | `0x10` | 标记分区有效 |
| `GET_UPGRADE_STATUS` | `0x12` | 获取升级状态 |
| `ACK` | `0x0A` | 确认响应 |
| `NACK` | `0x0B` | 拒绝响应 |

### 🔒 安全升级流程

1. **获取分区信息** - 读取 A/B 分区状态，确定当前激活分区
2. **擦除目标分区** - 擦除非活动分区
3. **分块上传固件** - 按 1024 字节分块上传到目标分区
4. **验证完整性** - 验证固件 CRC 校验值
5. **标记有效** - 标记目标分区为有效状态
6. **切换启动分区** - 设置目标分区为下次启动分区
7. **完成** - 升级成功，设备重启后从新分区启动

### 安全保障机制

- **原子切换**: 分区切换是原子操作，要么成功要么失败
- **状态标记**: 每个分区有独立的有效/无效状态标记
- **回滚保护**: 备用分区始终保留上一个稳定版本
- **断电恢复**: Bootloader 启动时检查分区有效性，自动回退到有效分区

## FPGA 端 Bootloader 要求

为了配合本应用的 A/B 双备份机制，FPGA 的 Bootloader 需要实现以下功能:

1. **双分区 Flash 布局**
   - 分区 A: 起始地址 0x000000, 大小 512KB
   - 分区 B: 起始地址 0x080000, 大小 512KB
   - 配置区: 存储分区状态和启动标志

2. **启动逻辑**
   - 读取配置区获取当前激活分区
   - 验证分区有效性 (CRC 校验)
   - 如果当前分区无效，自动切换到备用分区
   - 支持看门狗超时自动回退

3. **通信协议**
   - 实现上述所有 USB 命令
   - 支持 1024 字节分块写入
   - 支持 Flash 擦除和 CRC 计算

## 注意事项

- 需要在支持 WebUSB 的环境中运行
- FPGA 设备需实现对应的 Bootloader 通信协议
- 首次连接时需要用户授权 USB 设备访问权限
- 建议在正式升级前先验证回滚功能是否正常
