# PDF 乐谱协同批注系统 - 产品需求文档 (PRD)

## 1. 项目概述

### 1.1 项目背景
开发一个支持多人实时协作的 PDF 乐谱批注 Web 应用，通过 WebRTC 技术实现低延迟的批注同步，为音乐学习者和演奏者提供高效的协同学习工具。

### 1.2 目标用户
- 音乐教师和学生
- 乐队成员和指挥
- 音乐学习者个人

### 1.3 核心价值
- 实时协同批注，支持远程音乐教学
- 多种批注类型满足不同教学场景
- 批注历史版本管理，可回溯和恢复
- PDF 乐谱的便捷管理和预览

## 2. 功能需求

### 2.1 用户认证与权限管理
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 用户注册/登录 | 支持邮箱/密码注册登录 | P0 |
| 权限控制 | 创建者（完全控制）、协作者（编辑）、只读（查看） | P0 |
| 乐谱分享 | 生成分享链接，可设置权限 | P1 |

### 2.2 PDF 乐谱管理
| 功能 | 描述 | 优先级 |
|------|------|--------|
| PDF 上传 | 支持上传 PDF 乐谱文件 | P0 |
| 分页预览 | 支持乐谱多页切换预览 | P0 |
| 乐谱列表 | 查看用户拥有和协作的乐谱 | P0 |
| 乐谱删除 | 创建者可删除乐谱 | P1 |

### 2.3 批注功能
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 高亮批注 | 支持矩形高亮标注 | P0 |
| 自由画笔 | 支持手绘批注 | P0 |
| 文本标签 | 支持添加文本注释 | P0 |
| 节拍器标记 | 支持标记节拍点 | P0 |
| 批注删除 | 支持删除已有批注 | P0 |
| 批注颜色 | 支持多种批注颜色选择 | P1 |

### 2.4 实时协同
| 功能 | 描述 | 优先级 |
|------|------|--------|
| WebRTC 连接 | 建立点对点实时连接 | P0 |
| 批注同步 | 低延迟同步批注操作 | P0 |
| 用户在线状态 | 显示当前在线协作者 | P1 |
| 光标位置同步 | 显示其他用户操作位置 | P2 |

### 2.5 版本控制
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 自动保存 | 操作自动保存版本 | P0 |
| 版本列表 | 查看历史版本记录 | P0 |
| 版本恢复 | 恢复到指定历史版本 | P0 |
| 版本对比 | 查看版本间差异 | P2 |

## 3. 非功能需求

### 3.1 性能要求
- WebRTC 同步延迟 < 100ms
- PDF 首次加载时间 < 3s
- 支持至少 10 人同时在线协作

### 3.2 兼容性要求
- 支持主流现代浏览器（Chrome、Firefox、Safari、Edge）
- 响应式设计，支持桌面端和平板

### 3.3 安全要求
- 用户密码加密存储
- WebRTC 连接加密
- 权限验证中间件

## 4. 界面设计要求

### 4.1 整体风格
- **设计方向**: 专业简约风格，注重内容可读性
- **主色调**: 深靛蓝 (#1e3a5f) 为主，辅以金色 (#d4af37) 点缀
- **字体**: 标题使用 Playfair Display（优雅衬线体），正文使用 Source Sans Pro（清晰无衬线）
- **背景**: 浅米白色纹理背景，营造纸质乐谱质感

### 4.2 核心页面
- 登录/注册页：简约优雅的表单设计
- 乐谱列表页：卡片式布局，显示乐谱封面缩略图
- 协作编辑页：左侧工具栏 + 中央画布 + 右侧版本/用户面板

## 5. 验收标准

- 成功上传并预览 PDF 乐谱
- 四种批注类型均可正常使用
- 多人同时操作时批注实时同步
- 版本历史可查看并成功恢复
- 权限控制生效
