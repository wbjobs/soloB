# WebRTC音视频录制平台 - 产品需求文档

## 1. 项目概述

### 1.1 项目背景
开发一个基于WebRTC的音视频录制平台，支持麦克风与屏幕共享同时录制，后端采用Node.js + FFmpeg处理视频流，集成OpenAI Whisper API自动生成双语字幕并烧录到视频中。

### 1.2 项目目标
- 提供高质量的音视频录制体验
- 实现自动化的视频处理流程
- 支持中英文双语字幕生成与烧录
- 提供直观的视频时间轴交互

### 1.3 目标用户
- 在线教育讲师
- 会议录制人员
- 内容创作者
- 企业培训部门

## 2. 功能需求

### 2.1 录制功能
- **麦克风录制**：捕获系统音频输入
- **屏幕共享录制**：捕获屏幕内容，支持选择特定窗口
- **同时录制**：麦克风+屏幕共享同步录制
- **视频分段**：每5分钟自动分段存储
- **实时预览**：录制过程中实时预览画面

### 2.2 视频处理功能
- **FFmpeg转码**：视频流格式标准化
- **视频压缩**：自动优化视频文件大小
- **队列处理**：使用Bull队列异步处理任务
- **字幕生成**：集成Whisper API进行语音识别

### 2.3 字幕功能
- **双语字幕**：同时支持中英文
- **字幕烧录**：将字幕永久嵌入视频
- **时间轴交互**：点击字幕跳转到对应视频位置
- **字幕编辑**：支持手动修正字幕内容

### 2.4 会话管理
- **录制会话列表**：查看所有历史录制
- **会话详情**：查看录制信息、分段视频、字幕
- **视频播放**：内置播放器支持分段视频连续播放
- **下载功能**：支持下载处理后的视频文件

### 2.5 数据库存储
- **录制会话**：存储会话元数据
- **分段视频**：记录每个视频段的信息
- **字幕数据**：存储时间轴和文本内容
- **任务状态**：跟踪视频处理进度

## 3. 非功能需求

### 3.1 性能要求
- 录制延迟 < 100ms
- 视频处理队列支持并发任务
- 页面加载时间 < 2s

### 3.2 兼容性要求
- 支持Chrome、Firefox、Edge现代浏览器
- 支持Windows、macOS平台
- 视频输出格式：MP4 (H.264 + AAC)

### 3.3 安全要求
- 录音录像权限明确提示
- 用户数据本地化存储
- API密钥安全管理

## 4. 用户界面设计

### 4.1 设计风格
- **主题**：专业、现代、科技感
- **主色调**：深蓝色系 (#165DFF)
- **辅助色**：青色 (#00B42A)、橙色 (#FF7D00)
- **背景**：深色模式为主，降低视觉疲劳

### 4.2 主要页面
- **录制控制台**：主操作界面，包含预览窗口和控制按钮
- **会话列表**：历史录制管理页面
- **视频播放器**：带时间轴和字幕的播放页面
- **设置页面**：录制参数、API配置

### 4.3 交互设计
- 录制按钮状态清晰指示（准备/录制中/暂停/停止）
- 时间轴支持拖拽和点击跳转
- 视频分段可视化展示
- 处理进度实时反馈

## 5. 技术架构概览

### 5.1 前端技术栈
- React 18 + TypeScript
- WebRTC API
- MediaRecorder API
- Socket.IO（实时通信）
- Tailwind CSS

### 5.2 后端技术栈
- Node.js + Express
- FFmpeg（视频处理）
- Bull（任务队列）
- PostgreSQL（数据存储）
- OpenAI Whisper API

### 5.3 数据流
1. 前端捕获音视频流 → 通过Socket.IO发送到后端
2. 后端接收流数据 → 分段存储临时文件
3. 录制结束 → 触发Bull队列处理任务
4. 任务执行 → FFmpeg转码 + Whisper字幕生成
5. 字幕烧录 → 生成最终视频文件
6. 数据持久化 → 存储到PostgreSQL
